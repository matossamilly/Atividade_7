# 📚 Lista de Exercícios: Algoritmos e Lógica de Programação

Este repositório contém a resolução da lista de exercícios prática desenvolvida em dupla. O foco principal é o desenvolvimento de raciocínio lógico através de Pseudocódigo e representação visual via Fluxogramas.

## 🚀 Sobre o Projeto

O objetivo deste trabalho é aplicar conceitos fundamentais de programação, como estruturas de decisão, laços de repetição e manipulação de variáveis. Através da criação de algoritmos, exercitamos a capacidade de decompor problemas complexos em passos lógicos e sequenciais.

## 🛠️ Ferramentas Utilizadas

* **Flowgorithm:** Utilizado para a criação, visualização e teste dos fluxogramas (.fprg).
* **Portugol / Pseudocódigo:** Utilizado para a escrita estruturada do algoritmo em linguagem humana.
* **Git & GitHub:** Para o controlo de versão e colaboração entre a dupla.
